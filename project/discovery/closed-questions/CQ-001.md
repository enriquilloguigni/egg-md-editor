# CQ-001 — Tamaño objetivo de documento y latencia certificable de la sincronización bidireccional

## Pregunta

¿Qué tamaño de documento target y qué latencia de reflejo entre paneles garantiza v1 para la sincronización bidireccional?

## Respuesta

Target de 1.000.000 de caracteres por documento y latencia de sincronización bidireccional < 500 ms.

## Decisión

v1 garantiza un target de 1.000.000 de caracteres y una latencia de sincronización bidireccional < 500 ms; al redactar el NFR se precisará el percentil p95 y el hardware base.

## Impacto

Umbrales NFR de rendimiento en Project Spec y AC de fluidez del sync.
