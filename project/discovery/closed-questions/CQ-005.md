# CQ-005 — Múltiples documentos abiertos simultáneamente en v1

## Pregunta

¿v1 permite múltiples documentos abiertos simultáneamente?

## Respuesta

No: una sola ventana con un único documento a la vez.

## Decisión

v1 describe una sola ventana con un único documento abierto a la vez.

## Impacto

Estructura de la aplicación (Architecture), pantallas/estados de ventana en la Feature Spec y orden del Roadmap.
