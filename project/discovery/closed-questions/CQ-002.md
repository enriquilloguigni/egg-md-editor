# CQ-002 — Versiones mínimas de OS soportadas en v1

## Pregunta

¿Qué versiones de OS soporta v1?

## Respuesta

Las versiones de OS que soporta .NET 10: es una dependencia del ambiente de ejecución, no una decisión del producto.

## Decisión

v1 soporta las versiones de OS que soporta .NET 10.

## Impacto

Architecture (APIs disponibles, empaquetado, CI multi-OS) y presupuesto de pruebas por OS.
