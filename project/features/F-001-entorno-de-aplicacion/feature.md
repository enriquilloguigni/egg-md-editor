# F-001 — Entorno de aplicación

## Objetivo

Que la aplicación arranque en una sola ventana plenamente operativa: menús, barra de formato y atajos de teclado disponibles desde el primer momento, con la interfaz conmutable entre español e inglés sobre una arquitectura i18n extensible. Es la base sobre la que se apoyan el resto de Features de la entrega.
