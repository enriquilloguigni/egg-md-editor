# F-001 — Entorno de aplicación

## Objetivo

Que la aplicación arranque como entorno base en una sola ventana, con atajos de teclado y una interfaz conmutable entre español e inglés sobre una base de i18n extensible, y que desde el primer entregable se muestre la forma completa de la aplicación: la parte visual del menú principal persistente y de la barra de formato con el 100 % de sus opciones visibles, aún sin conectarlas a sus acciones (ADR-001).

## Prioridad

Prioridad: P1 — feature fundacional: primera entrega del roadmap v3, sin dependencias.

## Verificación independiente

Sí — su comportamiento puede comprobarse de forma aislada del resto de Features.

## Referencias Project Spec

- `BR-003`, `BR-007`, `FR-010`, `NFR-006` — aplicables; texto en Project Spec v2 (referencia, no copia).
- `FR-011`, `FR-012` — aplican **solo en su parte visual**, conforme a ADR-001; la conexión de cada opción a su acción queda fuera de esta Feature.

## Dependencias

Ninguna — F-001 no depende de ninguna otra Feature (roadmap v3).
