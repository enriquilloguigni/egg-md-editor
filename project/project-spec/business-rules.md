# Business Rules — egg-md-editor

```
| id     | regla |
|--------|-------|
| BR-001 | La aplicación debe funcionar 100% local y offline: sin telemetría, sin servicios de red y sin procesamiento de datos de terceros (C-001). |
| BR-002 | El proyecto se distribuye bajo licencia MIT; solo se admiten licencias permisivas compatibles con MIT en las dependencias, con la atribución declarada en un archivo de terceros y en la ventana Acerca de (C-002, CQ-003). |
| BR-003 | v1 debe mantener una sola ventana de aplicación con un único documento abierto a la vez (CQ-005). |
| BR-004 | El documento de trabajo debe ser un único archivo Markdown UTF-8 en disco local con bloque de metadatos delimitado al inicio (A-002). |
| BR-005 | La corrección ortográfica del documento debe regirse por el idioma declarado en su bloque de metadatos, independiente del idioma de la UI. |
| BR-006 | El diccionario personal de ortografía debe guardarse separado por idioma y compartirse entre todos los documentos del usuario (CQ-004). |
| BR-007 | La UI de v1 debe estar en español e inglés, sobre una arquitectura i18n extensible a más idiomas. |
| BR-008 | v1 debe distribuirse solo como código fuente con build local por el usuario, sin instaladores ni auto-update (A-001). |
| BR-009 | v1 debe soportar Windows, macOS y Linux en las versiones soportadas por .NET 10 (CQ-002). |
| BR-010 | El alcance de v1 debe ser el requerimiento completo sin recortes; el Roadmap solo ordena la entrega. |
```
