ADR-004 — Comando de captura (terminal) en design-system.md

Contexto: La tool `sdd-visual-capture` exige el formato `Comando de captura (terminal): <cmd>` para ejecutar capturas headless. `design-system.md` solo declara comandos por superficie (`ventana-principal`, `diálogo`, `ayuda`), que la tool no reconoce, por lo que no puede capturar evidencia visual de las superficies.

Decisión: Añadir a `design-system.md` (§6.6, Comandos de captura) la línea `Comando de captura (terminal): dotnet run --project project/implementation/scripts/EggMdEditor.VisualCapture/EggMdEditor.VisualCapture.csproj -- ventana-principal <SC> <escenario> <salida>`, manteniendo los comandos por superficie existentes.

Justificación: La captura headless necesita un comando canónico reconocible por la tool; los comandos por superficie actuales no bastan. Impacto integrado: modifica `design-system.md`, artefacto aprobado bajo `DESIGN_APPROVED`; no cambia el comportamiento del sistema ni el alcance, solo habilita la captura de evidencia visual para `PLAN_COVERED`. Requiere re-aprobación de `DESIGN_APPROVED`.

Consecuencias: Actualizar `design-system.md` con la línea añadida; re-gate `DESIGN_APPROVED`; ejecutar las capturas headless para los estados visuales declarados en los Run.
