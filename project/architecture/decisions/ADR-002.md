ADR-002 — F-001: Spec sobre mockup, tema visible y cierre de hallazgos de verificación

Contexto: La verificación de F-001 (Spec v1, Plan v1, Run v1, Execution E-002) devolvió «Plan no cubierto» con HV-001..HV-010. El mockup de SC-001 muestra tres columnas y cinco controles, mientras la Spec (BR-F001-008) exige solo menú y barra con el área de documento vacía; FR-012 y DS-001 exigen el «100 %» de una barra cuyo inventario no estaba fijado (HV-002, HV-003). Además, OP-002/TR-008/TR-009 no tienen disparador visible (HV-004), los seis rótulos de menú carecen de navegación secuencial y quedan pruebas E2E, iconos y API especulativa por corregir.

Decisión:
1. Rige la Spec sobre el mockup: SC-001 muestra solo el menú principal y la barra de formato; el área de documento queda vacía. El inventario normativo de FR-012 es el de 12 controles de `requerimiento.txt` en orden de escritura: énfasis, encabezados, listas, cita, código, enlace, imagen, tabla, nota al pie, fórmula, diagrama e índice. Spec, Plan y mockup se actualizan a v2.
2. Se añade en Herramientas la entrada visible `Tema` (Claro/Oscuro/Sistema), enlazada a OP-002 y TR-008/TR-009, con captura del estado oscuro.
3. Los seis rótulos de menú se muestran como botones y se añaden dos botones de navegación secuencial: uno aumenta el rótulo seleccionado (avanza al siguiente) y otro lo disminuye (retrocede al anterior).
4. Se corrigen todos los hallazgos restantes: pruebas E2E de AC-005/AC-006/AC-007, librería de iconos MIT-compatible con atribución y eliminación de alias y API especulativa.

Justificación: La Spec aprobada es el artefacto rector y el mockup no puede contradecirla; fijar los 12 controles y su orden hace verificable el «100 %» y retira del código una decisión no trazada. La entrada de tema da disparador observable a OP-002/TR-008/TR-009 y el estado oscuro aporta evidencia visual. Los botones de menú con navegación secuencial hacen operable la barra de rótulos sin ambigüedad de interacción. Las correcciones restantes cierran los hallazgos abiertos. Impacto: Spec v2, Plan v2 y mockups v2; Implementation con T-015..T-019; nueva Execution/Result y re-gate PLAN_COVERED. No cambian el stack .NET 10/Avalonia ni el alcance offline.

Consecuencias: Actualizar Spec, Plan y mockups a v2; recapturar SC-001 con el área de documento vacía, los 12 controles y el estado oscuro. Implementar T-015..T-019, añadir las pruebas E2E de AC-005/AC-006/AC-007, sustituir los glifos por la librería de iconos con atribución y eliminar alias y API especulativa. Emitir nueva Execution y nuevo Result, y volver a superar PLAN_COVERED. El resto de la superficie sin acción se mantiene según ADR-001; la conmutación de tema deja de ser inerte.
